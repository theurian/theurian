## The instrument, and why it is not `git grep`

Every key runs on **wrap-joined, whitespace-collapsed blocks**, and the
difference is not cosmetic. The WatchDog ruling's own object key, run two ways
over the same scope on this branch (`.theurian/`, `docs/work-logs/` and
`tools/audit/` excluded from both):

| Pass | Result |
| :-- | --: |
| line-oriented (`git grep -nP`) | **19** lines |
| wrap-aware (this instrument) | **31** sentences |

The twelve the line pass does not return whole are sentences typed across a
wrap, and #461's shipped claim — *"nothing reads that file today"*, whose object
is named one clause and one source line earlier — is one of them.

**The scope is half the measurement, so both scopes are stated.** The same key
over the *whole* tracked tree returns 20 lines at the branch base `141cf6f` and
30 at `f6e75fb`, and nothing in the repository's claims changed in between: the
difference is this branch's own audit ledgers and this page, which quote the
sentences they classify. That is why the census excludes `tools/audit/` from its
own population, and why a number here without its scope beside it would be
unreadable within a day.

The governed population at the same commit: **485 files**, **64,982 sentences**.
What the instrument does not read, printed rather than assumed:
`.sh` ×3, `.css`, `.html`, `.js`, `.lock`, `.png`, `.svg`, `.txt`, and 10 files
with no suffix at all.

## Class 4 — sha-like anchors

**Population:** 134 occurrences over 47 distinct tokens in `docs/`. 105
occurrences resolve on `origin/main`. **29 occurrences over 20 distinct tokens do
not**, and none of them carries a pull-request qualifier.

Twelve of those twenty are **real commits that are not on `main`**: `git cat-file
-t` says `commit` in a checkout that still holds the branch, and
`git merge-base --is-ancestor <token> origin/main` says no — so the anchor
resolves for whoever wrote it and for nobody who cloned the repository.

```
1a37c86  4bfec1d  1cc2fa8  67727eb  a8c1ce3  b8d2030
db36089  2793d7b  b8fa3e3  61747b3  6087be4  dc6aa79
```

**#463's population is twelve, not the two ADR-0008 members known when it was
filed.** `4bfec1d` and `1cc2fa8` are those two; the other ten are in ADR-0007,
ADR-0024, ADR-0027 and the threat model, and they carry dated measurements,
remedy provenance and "as of #26" claims.

The other eight are not object ids at all — illustrative content and state hashes
inside quoted refusals and sample `doctor` tables. They are **classified rather
than filtered out of the key**, the precedent #470 set for the Mermaid hex
colours it met in the same position.

Two structural narrowings are recorded in the module rather than applied
silently: a token inside a URL is a link target (every GitHub comment anchor is a
ten-digit run inside one), and a token with no `a`–`f` is a decimal quantity. The
second has a stated false-clear risk of one tree in 16⁷.
