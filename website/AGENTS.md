# Website contribution rules

The website is a product site and technical publication.

Requirements:
- explain the user problem before implementation detail
- accurately distinguish shipped, experimental, and planned functionality
- optimize for accessibility, performance, crawlability, and mobile rendering
- use meaningful titles, descriptions, canonical URLs, and useful internal links
- avoid thin SEO pages, keyword stuffing, fake dashboards, and unsupported hype
- demos must represent real Theurian workflows

Do not modify core product implementation from website tasks.
